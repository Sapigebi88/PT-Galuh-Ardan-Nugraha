# Galuh Portfolio V10 — Liquid Glass Railway

Premium personal portfolio for Galuh Ardan Nugraha.

## Included
- Liquid-glass UI across Home, About, Projects, Contact and Access download page
- 5-language UI: Indonesia, English, Mandarin, Japanese, Arabic
- Arabic RTL support
- 5 Indonesian railway images, locally bundled and optimized for large displays
- KAI and Access by KAI logo assets supplied for the project cards
- BookingKAI Galuh → https://booking.kai.id/
- Galuh Apple Store → https://ibox.co.id/
- Access by Galuh → dedicated in-portfolio download page with Google Play and App Store links
- Scroll reveal, glass reflections, pointer-reactive highlights, moving railway marquee and slide transitions
- Responsive desktop/mobile layout

## Run
```bash
npm install
npm run dev
```

## Note on photo quality
The gallery assets are exported at large display dimensions and sharpened for the web. Upscaling cannot create detail that was not present in the original uploaded photos, so the final sharpness still depends on the source photo resolution.
